# Instrucciones para Claude Code

- Implementa solo componentes con documento en estado **Aprobado** en `docs/_INDICE_MAESTRO.md`. Si falta un documento aprobado, detente y avisa.
- Antes de programar, lee `docs/_ESTADO_PROYECTO.md`, `docs/marco-general/marco-general-proyecto.md` y el documento del componente. El stack, los nombres de entidad y las reglas transversales salen de ahí; no los redefinas.
- Si al implementar algo no calza con el documento, no improvises: regístralo y pide que se actualice el documento dueño.
